1. What is Generative AI?

Generative AI creates new content from patterns learned from large datasets. Depending on the model, it can generate text, images, audio, video or computer code.

2. How It Works

A generative model learns relationships in training data. When given an instruction or prompt, it predicts and produces an output that matches the requested context.

3. Prompt Engineering

Good prompts clearly state the task, context, constraints and desired format. Iterating on prompts helps improve the result.

4. Responsible Use

AI-generated information can contain errors. Verify important facts, protect private information and use generated content responsibly.
